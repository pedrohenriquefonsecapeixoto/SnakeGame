# Snake Game

Um clássico jogo da cobrinha focado na expansão contínua. Este projeto serve como uma base sólida na qual novas mecânicas, modos de jogo e desafios podem ser implementados.

## Sobre o Projeto

Este repositório não é apenas um clone do jogo clássico. A ideia é começar com a mecânica básica (mover, comer, crescer) e modificá-lo para deixar a jogabilidade menos repetitiva e mais divertida.

## Funcionalidades
* Movimentação em 4 direções.
* Geração aleatória de comida.
* Crescimento da cobra ao comer.
* Sistema de colisão (paredes e próprio corpo).
* Pontuação básica.

## 🗺️ Ideias
Como este é um projeto em constante evolução, aqui estão algumas ideias que podem ser adicionadas:

### Itens
- [ ] **Tesoura:** Corta a cobra pela metade.
- [ ] **Câmera Lenta:** Reduz a velocidade para manobras difíceis por um tempo.
- [ ] **Comidas Especiais:** Frutas douradas que valem mais pontos.

### Cenário e Obstáculos
- [ ] **Sistema de Fases:** Mapas, obstáculos e opções diferentes para alguns mapas

### Adicionais
- [ ] **Sistema de Skins:** Mude as cores e o formato da cobra.
